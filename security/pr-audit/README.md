# PR Audit Records

Each significant PR gets an AI-assisted audit: the reviewing agent reads the diff against
AGENTS.md laws + the rubric, produces findings, and the human dispositions them. The record
(transcript + findings + fixes) is committed here — this is the "PR audit output" artifact
for criterion 13.

Format per audit: `PR-<number>-audit.md` with sections: Scope · Findings (severity, file,
line, law/criterion) · Disposition · Verification (test/lint output proving the fix).
